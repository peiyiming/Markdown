# Markdown 商业化产品路线图

## 产品定位

一个面向个人创作者、知识工作者和移动办公用户的 Markdown 创作工具。

核心原则：**先做好本地创作体验，再逐步增加同步、分享和商业化能力。**

## V1：基础产品闭环

- Markdown 文档创建、编辑、保存
- 自动保存与重新打开
- Markdown 预览
- 最近文档列表
- 基础编辑快捷栏

## V1.5：生产力体验

- 文档重命名、删除、搜索
- 文件夹与标签
- Undo / Redo
- 图片插入
- 导出 HTML / PDF
- 深色模式

## V2：商业化基础设施

### 免费版
- 本地 Markdown 编辑
- 基础预览
- 有限文档管理

### Pro
- 云同步
- 多设备同步
- 高级主题
- PDF / HTML 高级导出
- 文档模板
- AI 写作辅助

## V3：增长与分享

- 分享链接
- 发布为网页
- 模板市场
- 团队空间
- 文档协作

## 技术演进

当前 MVP 采用轻量架构快速验证产品。

下一次大版本建议：

1. AndroidX
2. Kotlin 现代版本
3. ViewModel + StateFlow
4. Jetpack Compose
5. Room / DataStore
6. 模块化 Feature 架构
7. 可替换的同步与商业化服务层

## 商业化原则

商业化能力必须与核心编辑体验解耦。付费、账号、云同步和 AI 服务不能成为本地编辑器的单点故障。
